# Aurelia Glow Salon

A luxury beauty website that combines a **skincare e-commerce store** with a **salon appointment booking** experience.
Built with WordPress, Astra Theme, WooCommerce and Elementor (Free).

## Brand Style

| Item | Value |
|------|-------|
| Heading Font | Playfair Display |
| Body Font | Montserrat |
| Champagne | `#F3EAE0` |
| Espresso | `#1F1C1A` |
| Terracotta / Rose Gold | `#B86B58` |
| Cream | `#FAF7F2` |

## Tech Stack

- WordPress
- Astra Theme
- WooCommerce
- Elementor (Free)
- Custom HTML + CSS (HTML Widget)
